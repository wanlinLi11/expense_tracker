# Expense Tracker

A simple Python command-line program that adds up your spending by place or category.

## How to use

```
python3 expenses.py

```

Enter a place and an amount as many times as you like.
Press **Ctrl-D** to finish and see your summary.

## Example

```
---------- Summary ----------
tesco: €69.80
eat out: €18.00
-----------------------------
Total: €87.80
```

Built while learning Python with CS50.
